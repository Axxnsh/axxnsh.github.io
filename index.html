WCAG 2.2 AA Accessibility & QA Checklist

Testable acceptance criteria and guidelines for storefront components.

Accessibility Rules (Must Enforce)

  • Focus-Visible: Keyboard focus must render a visible 3px outline (`#146ef5`) with 2px offset.
  • Contrast Ratio: Text primary (`#000000`) on white surface meets > 4.5:1 ratio.
  • Keyboard Navigation: Every interactive element is reachable via `Tab` and executable via `Enter` or `Space`.

Anti-Patterns (Prohibited)

  • No Raw Hex Overrides: Do not introduce one-off spacing or hex values outside token definitions.
  • No Hidden Focus Indicators: Never set `outline: none` without providing explicit `:focus-visible` states.
  • No Non-Descriptive Actions: Action labels must clearly state outcome (e.g. "Add to Cart").
